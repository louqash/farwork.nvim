*remote-workspace.txt*  Local editing with remote clangd and builds

SETUP                                             *remote-workspace-setup*
Requires Neovim 0.11+, Python 3, Git, SSH and rsync 3+ locally.
Remote: Python 3, Git, rsync, clangd and a configured CMake project.
>
    require('remote_workspace').setup({ keymaps = false })
<
Setup registers commands; connections are opt-in. keymaps=true enables
<leader>rs/rb/rd for start/build/diff and <leader>us/ui for upload/status.
Use :checkhealth remote_workspace to check local prerequisites.

OPTIONS                                           *remote-workspace-options*
keymaps          Boolean; false by default. Install optional leader mappings.
rsync            Local executable name/path; defaults to "rsync".
clangd_args      Remote clangd flags; default background-index and clang-tidy.
build_command    Function(project) returning argv; default cmake --build.
upload_exclude   Function(relative_path) returning true to exclude extra uploads.
state_dir        Saved project settings directory; default stdpath('state').
cache_dir        Header cache parent directory; default stdpath('cache').

Build arguments are quoted automatically. Exclusions are additive and only
affect uploads. SSH identity/proxy settings come from ~/.ssh/config. Remote
environment activation is saved per project through :RemoteStart!.

COMMANDS                                          *remote-workspace-commands*
:RemoteStart          Connect from the local project root; reuse saved settings.
:RemoteStart!         Prompt for destination, environment and build directory.
:RemoteStatus         Show project and language-server status.
:RemoteRefresh        Restart remote clangd once uploads are idle.
:RemoteBuild          Sync saved files, then run CMake remotely.
:RemoteDiff[!]        Show remote unstaged [staged] diff. q closes the split.
:UploadStart [dest]   Upload files without starting remote clangd.
:UploadStatus        Show current transfer/queue state (after uploads start).
:UploadWait          Wait up to 30 seconds for uploads.
:UploadRetry         Retry a failed queue without discarding saved files.
:UploadStop          Stop an idle uploader and discard its pending queue.

BEHAVIOR                                          *remote-workspace-behavior*
Local files overwrite corresponding remote files. Git metadata, virtual
environments and build outputs are excluded. Deletions are not propagated.
RemoteStart checks that Git HEAD and branch match; it does not reconcile
history or run remote stash/reset/checkout. UploadStart has no Git guard.
Queues live in memory. Save buffers before quitting. Use one uploading editor
per remote project. C++ language-server requests require a live connection.

Saved state uses remote-projects.json and upload-projects.json under
stdpath('state'), retaining settings from the original dotfiles integration.

See README.md for installation, local clangd integration and detailed limits.
